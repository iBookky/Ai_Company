วิธีสมัคร Telegram Bot ใน 1 นาที (ฟรี 100%):
1. เปิดแอป Telegram แล้วค้นหาหาบอท @BotFather
2. พิมพ์คำสั่ง /newbot แล้วตั้งชื่อบอท → จะได้รับ HTTP API Token ทันที
3. นำ Token มาวางที่ช่องด้านล่าง แล้วกดบันทึกใช้งานได้เลย!
Step 1 — Bot Token
Step 2 — กำหนดห้อง Telegram Chat IDs (3 ระดับ)
Step 3 — ตัวตนของคุณ (Owner)
Step 4 — Telegram Webhook URL
