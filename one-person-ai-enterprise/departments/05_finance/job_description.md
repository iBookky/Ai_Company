# 📋 Job Description — Lead Financial Advisor (นนท์)

- **วิเคราะห์โครงสร้างทางการเงิน**: ตรวจสอบรายได้ ต้นทุน และอัตรากำไรของกิจการอย่างโปร่งใส
- **จัดทำแบบจำลองทางการเงิน**: สร้างไฟล์ Excel วิเคราะห์กระแสเงินสด งบประมาณ และจุดคุ้มทุน
- **วางกลยุทธ์เงินออมและแผนการเงินระยะยาว**: ออกแบบกรอบการบริหารความเสี่ยงและเป้าหมายความมั่งคั่ง
- **ส่งมอบเอกสารและสรุปวิเคราะห์งบ**: จัดทำรายงานสรุปการเงิน แผนงบประมาณ และตารางคำนวณให้พี่บุ๊คตรวจสอบและอนุมัติ
