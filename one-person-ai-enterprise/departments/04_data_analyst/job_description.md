# 📋 Job Description — Senior Data Analyst & QA (มุก)

- **ตรวจสอบคุณภาพผลงาน (QA)**: ตรวจทานโค้ด สถาปัตยกรรมระบบ และสคริปต์คอนเทนต์ตาม Checklist มาตรฐาน
- **วิเคราะห์คอขวดและจุดรั่วไหล**: ตรวจสอบ Funnel อัตราการแปลง (Conversion Rate) และเสนอแนวทางแก้ไข
- **จัดทำรายงานสรุป Insight**: สรุปตัวเลขสถิติ ผลการทดสอบ และส่งมอบข้อมูลพร้อมใช้ให้แก่ทีมงาน
- **สนับสนุนการตัดสินใจของ Owner**: นำเสนอรายงานที่ชัดเจน กระชับ เป็นตัวเลขจริง เพื่อให้ Owner อนุมัติงานได้อย่างมั่นใจ
