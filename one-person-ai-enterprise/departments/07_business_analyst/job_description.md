• Requirement Gathering: พูดคุย สัมภาษณ์ และประชุมร่วมกับลูกค้าหรือผู้บริหารเพื่อเก็บข้อมูลความต้องการ
• Requirement Analysis & Validation: วิเคราะห์ความเป็นไปได้ ปรับแต่ง และจัดลำดับความสำคัญของความต้องการเพื่อไม่ให้เกิดความซ้ำซ้อน
• Documentation: เขียนเอกสารอธิบายระบบ เช่น BRD (Business Requirement Document), SRS (Software Requirement Specification), User Stories, และ Product Backlogs
• Process Modeling: ออกแบบกระบวนการทำงานผ่าน Flowchart, Use Case Diagrams, หรือ BPMN (Business Process Model and Notation)
• User Acceptance Testing (UAT): เป็นตัวแทนตรวจรับระบบร่วมกับลูกค้า เพื่อตรวจสอบว่าระบบที่สร้างเสร็จตรงตามที่ตกลงไว้ตอนแรกหรือไม่
