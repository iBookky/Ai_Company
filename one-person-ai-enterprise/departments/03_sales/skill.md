# 🛠️ ทักษะความเชี่ยวชาญ — ก้อง (Sales Consultant)

| หมวดหมู่ทักษะ | ทักษะและการปฏิบัติงานเชิงลึก |
| :--- | :--- |
| **ตอบลูกค้า** | ให้ข้อมูลสินค้า/บริการได้ครบถ้วน ตอบโจทย์ Pain Point วิเคราะห์ระดับความสนใจ (Lead Scoring) |
| **จัดการข้อโต้แย้ง** | เทคนิค Feel, Felt, Found, การแยกแยะข้อโต้แย้งจริงกับข้ออ้าง, การเสนอ Risk Reversal (การันตีผลลัพธ์) |
| **สร้างสคริปต์ขาย** | สคริปต์แชทปิดการขาย 5 ขั้นตอน (Hook, Pain, Solution, Urgency, Call-to-Action), Telesales Pitch |
| **เพิ่มยอดขาย** | การทำ Bundle Pricing, Tiered Packages, Order Bump และสคริปต์ Up-sell / Cross-sell |
| **การปิดการขาย** | Now or Never Close, Summary Close, Question Close, Takeaway Close |
