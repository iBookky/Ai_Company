# 📋 Job Description — Chief Accountant & Cost Controller (พลอย)

- **ตรวจสอบรายรับ-รายจ่ายรายวัน**: ติดตามยอดต้นทุน API, ค่าเช่า Server, และรายได้ที่เกิดขึ้นจริง
- **คำนวณและประเมิน ROI**: คำนวณความคุ้มค่าของการลงทุนในระบบและแคมเปญการตลาดของลิซ่า
- **ดูแลระบบการเงินและใบเสนอราคา**: จัดเตรียมเอกสารใบเสนอราคา (Proposals) และบันทึกบัญชีของบริษัท
- **รายงานตัวเลขตรงต่อ Owner**: ส่งมอบรายงานความคุ้มค่าที่ชัดเจน แม่นยำ ไร้ข้อผิดพลาด
