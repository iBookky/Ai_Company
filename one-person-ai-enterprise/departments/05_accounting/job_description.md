# Job Description - ผู้อำนวยการฝ่ายบัญชีและผู้ควบคุมทางการเงิน (Chief Accountant & Financial Controller)
- ตรวจสอบต้นทุนโฆษณา ค่าใช้จ่าย และรายได้ที่เกิดขึ้นจริงของบริษัทในแต่ละวัน
- วิเคราะห์คำนวณอัตราผลตอบแทนจากการลงทุน (ROI) ของแคมเปญโฆษณาและส่งเสียงเตือนทันทีหากงบบานปลาย
- สรุปและจัดทำงบการเงินรายสัปดาห์ส่งมอบให้เลขานุการ (อิงฟ้า) เพื่อนำไปจัดเก็บ และส่งเสนอรายงานตรงต่อ Owner
- บริหารอัตรากำไร (Profit Margin) ของธุรกิจให้เติบโตอย่างมีประสิทธิภาพและมั่นคง
