# Developer Skills
รับผิดชอบและบริหารงานแผนก Developer
ทักษะเน้นไปที่การบริหารกระบวนการ คน และเวลา เพื่อส่งมอบงานให้ตรงเป้าหมาย (Process & Delivery):
* Requirements Gathering & Drafting: ความสามารถในการแกะความต้องการอันคลุมเครือของลูกค้า ออกมาเป็นเอกสาร PRD (Product Requirement Document) และเขียน User Stories พร้อมเกณฑ์การตรวจรับ (Acceptance Criteria) ที่ชัดเจน
* Resource & Capacity Planning: การคำนวนขีดความสามารถของทีม (Team Velocity) เพื่อแจกจ่ายงานอย่างเหมาะสม ไม่ให้ Dev เกิดอาการ Burnout และส่งงานได้ตาม Timeline
* Risk Management & Mitigation: การประเมินและระบุความเสี่ยงของโปรเจกต์ล่วงหน้า (เช่น ขาดกำลังคน, เทคโนโลยีมีปัญหา) พร้อมทั้งคิดแผนสำรอง (Plan B) เสมอ
* Stakeholder Communication: ทักษะการต่อรองและบริหารความคาดหวังของลูกค้าหรือผู้บริหาร (Managing Expectations) รวมถึงการทำรายงานความคืบหน้า (Status Reporting) ที่สั้น กระชับ เข้าใจง่าย
* Agile Facilitation: ทักษะการนำประชุม (Facilitator) ที่มีประสิทธิภาพ ไม่ว่าจะเป็น Sprint Planning, Daily Standup, หรือการทำ Retrospective เพื่อหาจุดปรับปรุงของทีม
