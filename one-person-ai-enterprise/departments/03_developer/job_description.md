# Job Description - นักพัฒนาซอฟต์แวร์ฟูลสแต็ก (Full-Stack Developer)
- ตรวจสอบความเสถียรของหน้าเว็บและระบบการชำระเงินไม่ให้สะดุดหรือล่ม
- นำการออกแบบหน้า Landing Page หรือแนวทางแคมเปญของลิซ่ามาเขียนโค้ดและอัปเดตขึ้นระบบจริงอย่างรวดเร็ว
- เขียนโค้ดชุดทดสอบและทำระบบตรวจสอบแก้ไขบั๊กอัตโนมัติเพื่อรับรองทราฟฟิกลูกค้าที่เพิ่มขึ้น
- ปรับปรุงการใช้งานและประสิทธิภาพของระบบเพื่อป้องกันและลดอัตราการละทิ้งการจ่ายเงินของลูกค้า
