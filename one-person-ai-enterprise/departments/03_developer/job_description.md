# 📋 Job Description — Lead Developer (บิ๊นท์)

- **พัฒนาระบบซอฟต์แวร์**: เขียนโค้ด Backend API, Frontend Dashboard, เชื่อมต่อระบบ Database และ Automation Scripts
- **รักษามาตรฐานและคุณภาพ**: เขียน Clean Code, Type Safety และสร้างชุด Automated Tests ครอบคลุม 100%
- **จัดเตรียมแพ็กเกจส่งมอบ**: รวบรวม Source Code, คู่มือ และรายงานผลการรัน พร้อมส่งให้ Owner ยืนยันปิดงาน
- **ประเมินการขยายทีม AI**: เสนอขอเปิดตำแหน่ง AI ผู้เชี่ยวชาญเฉพาะทางเมื่อระบบต้องการ
