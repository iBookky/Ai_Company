# 📋 Job Description — Cloud DevOps Specialist (ก้อง)

- **ดูแลระบบคลาวด์และเซิร์ฟเวอร์**: ติดตั้ง ตรวจสอบ และบริหารจัดการ Cloud Instances และ Docker Containers ให้พร้อมใช้งาน 24/7
- **พัฒนาระบบ CI/CD Automation**: สร้าง Automation Pipelines เพื่อ Build, Test และ Deploy ซอฟต์แวร์ที่ บิ๊นท์ พัฒนาขึ้น
- **จัดเตรียมความพร้อมในการส่งมอบ**: รายงานสถานะ Server Health และผลการตรวจสอบความปลอดภัยก่อนส่งให้ Owner ตรวจรับ
- **ร่วมมือด้านความปลอดภัย**: ประสานงานกับทีม Dev และ Data เพื่อรักษาความปลอดภัยของระบบฐานข้อมูลและ API Endpoints
